# Blomi 🌙

A monthly to-do list app that adapts to a woman's menstrual cycle — built with [Lovable](https://lovable.dev).

## Overview

Blomi helps users plan their month while staying in sync with their body. Users log their cycle start date, and the app predicts their current phase (menstrual, follicular, ovulation, luteal) and adjusts daily task suggestions accordingly — e.g. avoiding high-intensity activities during menstruation, favoring social/active plans during ovulation.

## Features
- **To-Do tab** — monthly task input at the top; AI-organized daily calendar at the bottom, with task suggestions filtered by cycle phase
- **Profile tab** — name, age, app language, light/dark mode, and reset button
- **Cycle Tracker tab** — calendar-based cycle logging (Flo-style), automatic phase prediction, current phase indicator
